# 0014 — M2 demo texture asset: build the fixture + lock the asset contract (ADR-0002/0007)

**What to build:**

Build a legal, pipeline-consumable demo fixture so 0009 can validate its texture upload without
inventing an asset contract. **0014 builds the fixture; 0009 consumes/verifies it.** 0014 does not
exercise 0009's runtime pipeline and needs no GL.

Relationship through the existing M2 asset contract:

```text
manifest (v1, unchanged)
  │ geometry
  ▼
OBJ ──mtllib──▶ MTL ──map_Kd──▶ PNG
                                 │
                                 ▼
                   ObjLoadResult (CPU)
                                 │
                                 ▼
                     SubMesh → Material → diffuseTextureRef
                                                 │  (0009 continues from here:
                                                 │   Texture::fromFile → GL_SRGB8_ALPHA8
                                                 │   → shader → render)
```

0014 proves the fixture resolves to `Material::diffuseTextureRef` (CPU level). Everything below
`diffuseTextureRef` is 0009's responsibility.

## Scope

**0014 owns:** fixture placement, reproducible PNG generator, OBJ/MTL fixture + `map_Kd`,
manifest-unchanged decision, path-contract conformance, demo-asset classification.

**0014 does NOT own:** `Texture::fromFile` / `GL_SRGB8_ALPHA8` / shader sampling / `finalAlpha` /
GPU rendering / reference-PNG E2E verification (all 0009), nor the path-safety *enforcement*
(0013).

## Locked: demo fixture subtree

The fixture lives as a single self-contained subtree so `map_Kd` stays **relative and free of
`../`** while remaining OBJ-directory-relative (ADR-0007):

```text
assets/
├── geometry/
│   └── placeholders/
│       └── demo_checker/
│           ├── demo_checker.obj
│           ├── demo_checker.mtl
│           └── textures/
│               └── demo_checker.png
└── tools/
    └── generate_demo_texture.py
```

```mtl
map_Kd textures/demo_checker.png
```

- `map_Kd` resolves from the OBJ directory: `demo_checker/` + `textures/demo_checker.png` =
  `demo_checker/textures/` — OBJ-directory-relative, no `../`, no absolute path, passes the
  ADR-0007/0013 predicate.
- The demo texture is runtime-consumable fixture data scoped **under the fixture subtree**, not a
  top-level `assets/textures/` pool. `assets/references/` (official Noto visual ground truth)
  stays fully independent — enabling the "reference PNG must never be a texture" check.
- Filename is demo-focused, never emoji-named (`smile.png` etc.), so it cannot be mistaken for an
  official Noto asset.

## Locked: manifest unchanged (for this fixture)

Manifest v1 stays as-is. **For this fixture**, the diffuse texture is resolved through
`geometry → OBJ → mtllib → MTL → map_Kd`; no manifest texture field is introduced. This is a
fixture-scope statement, not a claim that `map_Kd` is the only possible texture source in the
project's future.

## Locked: generator without new dependencies, deterministic

`assets/tools/generate_demo_texture.py` — Python **standard library only** (already an available
toolchain; no Pillow/ImageMagick or any third-party package; build-time tool, not a runtime
dependency). To avoid the generator becoming a mini PNG library, output is a minimal RGBA8 image:
small fixed dimensions, fixed checker pattern, no timestamp / no ancillary metadata.

**Determinism criterion:** the same arguments must produce **byte-identical PNG output** when the
generator is run repeatedly.

## Path contract (ADR-0007 conformance, not 0013 dependency)

`map_Kd` must be a relative path with no absolute form and no `../` — e.g. `textures/demo_checker.png`
resolved relative to the fixture's OBJ directory; any path that satisfies the same contract is
acceptable. An absolute or `../`-escaping path must never ship. 0014 conforms to the contract
defined by ADR-0007; the shared predicate that enforces it is 0013's implementation — that
enforcement is *not* a prerequisite of 0014.
